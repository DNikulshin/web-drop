# Web app

Это фронтенд часть Web Drop на Next.js 16. На текущем этапе приложение служит точкой входа для интеграции с API: сессии, загрузка файлов, WebSocket и базовый UI.

## Что здесь уже есть
- Базовая Next.js-структура в App Router
- Подключение к monorepo и shared пакетам
- Готовая точка для интеграции с Fastify API

## Запуск
```bash
pnpm --filter web dev
```

Откройте http://localhost:3000.

## Сборка и проверка
```bash
pnpm --filter web build
pnpm --filter web lint
```
